Building it is half the job. Keeping it correct is the other half.

A sample of production issues found and resolved — the kind of work that doesn't show up in a project list but is most of what real software engineering is.

FIXED
Ledger cross-posting from fuzzy account matchingJournal entries were matching loosely and cross-posting across every Chart of Accounts entry, throwing off the General Ledger vs. Trial Balance. Resolved with strict accountCode matching and a targeted repair script for already-corrupted balances.
FIXED
Silent failure on large API responsesUser lists were returning empty with no visible error — the payload was silently too large due to embedded base64 profile images. Fixed by excluding images from the API response and adding client-side compression on upload.
FIXED
Session validator clearing auth incorrectlyAny non-401 error was being treated as an expired session, logging users out unnecessarily. Narrowed the validator to only clear auth on genuine authentication failures.
FIXED
Crash from unpopulated reference fieldsThe Emails page crashed whenever a sender reference wasn't populated on the returned document — a common failure mode in MongoDB-backed apps that don't guard against missing joins.
